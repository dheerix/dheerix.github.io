## Logging rule

Each session should record:

1. What was practiced.
2. What was implemented or explained without assistance.
3. Corrections and deeper mental models.
4. Gaps found.
5. The next session's continuation point.

The goal is not to prove how much was covered. The goal is to make weak spots visible and systematically remove them.
