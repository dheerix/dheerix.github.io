# Senior Engineering Interview Kit

This directory is the execution layer for senior software engineering interview preparation.

It is optimized for the Verily role family:

- Technical Lead, Workbench User and Account Management
- Precision Health Platform Engineer
- Senior Full-Stack Engineer
- Developer Platform Engineer
- Senior Software Engineer across platform and product systems

The preparation priority is:

```text
Coding and DSA
    ↓
System design
    ↓
Technical depth
    ↓
Communication under pressure
    ↓
Project and behavioral evidence
```

Project explanation is already a relative strength. Most preparation time should therefore be spent performing technical work without AI assistance and explaining decisions aloud.

## Non-Negotiable Practice Rules

1. Complete coding attempts without Codex, autocomplete, or copied solutions.
2. Speak during coding and system-design practice.
3. Use Codex only after an attempt to review reasoning, correctness, alternatives, and communication.
4. Re-solve missed problems from a blank editor within 24–72 hours.
5. Record system-design sessions and review where the explanation became unclear.
6. Use personal project evidence for experience questions; do not convert hypothetical knowledge into claimed experience.

## Readiness Standard

The kit is complete when the candidate can:

- solve a representative medium coding problem in 35 minutes
- produce correct, compilable code without AI assistance
- explain complexity and test edge cases
- drive a 45-minute system-design interview
- discuss failure modes, security, observability, and trade-offs
- answer technical follow-ups without hiding behind technology lists
- distinguish personal contribution from team outcome
- communicate uncertainty clearly and propose a method for resolving it
