# 02 - Career Journey

# Career Journey

> Careers are not defined by job titles—they are defined by the evolution of the problems we choose to solve.

---

# Overview

My engineering career has been driven by curiosity rather than specialization. Each stage introduced new technical challenges, broader system thinking, and greater ownership.

Over time, my focus has evolved from building applications to designing platforms, modernizing systems, and enabling engineering teams through scalable solutions.

---

# Phase 1 — Discovering Software Engineering

## Objective

Learn how software is built.

### Focus

- Programming fundamentals
- Object-oriented design
- Mobile development
- Desktop applications
- Web applications

### Technologies

- Java
- C#
- .NET
- Android
- PHP
- SQL

### Lessons

This phase established the habit of learning new technologies by understanding concepts rather than memorizing frameworks. Working across different languages showed that software engineering principles are more durable than any individual technology.

---

# Phase 2 — Becoming a Full-Stack Engineer

## Objective

Deliver complete software solutions.

### Focus

- Frontend development
- Backend services
- Databases
- APIs
- Enterprise applications

### Technologies

- ASP.NET
- MVC
- JavaScript
- React
- SQL Server
- REST APIs

### Lessons

Building complete applications highlighted the importance of balancing user experience, business requirements, and maintainable backend systems.

# Phase 3 — Enterprise Commerce

## Objective

Understand software at enterprise scale.

### Focus

- Enterprise search
- Commerce platforms
- Promotion systems
- Backend APIs

### Key Contributions

- Enterprise search platform

# Phase 4 — Healthcare Technology

## Objective

Build software where reliability directly impacts people's lives.

### Focus

- Healthcare workflows
- AI-assisted features
- Secure systems
- Cloud-native services

### Lessons

Healthcare engineering reinforced the importance of reliability, privacy, and designing software that supports professionals making critical decisions.

---

# Phase 5 — Marketplace Platforms

## Objective

Modernize large-scale enterprise systems.

### Focus

- Platform modernization
- Cloud migration
- Distributed services
- Production engineering
- AI integration

### Key Contributions

- Marketplace platform evolution
- Cloud-native services
- Production support
- Feature ownership
- Cross-functional collaboration
- AI-powered moderation

### Lessons

This phase emphasized that modernization is not simply replacing technology—it is preserving business continuity while enabling future growth.

---

# Phase 6 — Artificial Intelligence

## Objective

Build trustworthy AI systems for production.

### Focus

- LLM integration
- Machine learning classifiers
- Human-in-the-loop workflows
- AI governance
- Observability
- Evaluation

### Lessons

Production AI requires much more than integrating language models. It demands careful consideration of reliability, safety, monitoring, evaluation, and business outcomes.

Several experiences significantly shaped my engineering mindset:

- Working across multiple programming languages and ecosystems.
- Contributing to enterprise-scale commerce and marketplace platforms.
- Participating in large modernization initiatives.
- Building production AI capabilities.
