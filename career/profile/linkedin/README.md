# LinkedIn 2.0

Public-facing professional positioning built from the canonical career record.

## Structure

- `01_HEADLINE.md` - profile headline options and recommended final version
- `02_ABOUT.md` - first-person professional narrative
- `03_EXPERIENCE.md` - role summaries with context and impact
- `04_FEATURED.md` - featured work and external proof points
- `05_PROJECTS.md` - polished project summaries
- `06_SKILLS.md` - recruiter-facing skill set
- `07_RECOMMENDATIONS.md` - recommendation request guidance
- `08_BANNER.md` - profile banner direction
- `09_CUSTOM_URL.md` - profile URL guidance
- `10_POSTING_STRATEGY.md` - content cadence and topics

## Approach

LinkedIn should complement, not duplicate, the resume library.

It should communicate:

- who I am
- what I build
- how I think
- where I add value
- what kinds of problems I solve
