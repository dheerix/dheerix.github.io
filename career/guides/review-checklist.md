# Artifact Review Checklist

## Business

- [ ] Business problem clearly explained
- [ ] Success criteria defined
- [ ] Stakeholders identified

## Engineering

- [ ] Architecture explained
- [ ] Major decisions documented
- [ ] Trade-offs discussed
- [ ] Alternatives considered

## Production

- [ ] Deployment covered
- [ ] Observability described
- [ ] Failure modes discussed

## Evidence

- [ ] Metrics included where available
- [ ] No unsupported claims
- [ ] Ownership clearly identified

## Learning

- [ ] Lessons captured
- [ ] Future improvements documented

## Reusability

- [ ] Resume bullets extracted
- [ ] Interview story prepared
- [ ] Promotion evidence mapped
