# Career Snapshots

Quarterly observability for career evolution. This is deliberately small: it observes evidence already produced by `engineering/`, `evidence/`, projects and real work; it does not create another roadmap.

## Cadence

Create one snapshot per quarter using `YYYY-QN.md`. Reassess the same six dimensions:

- Technical Depth
- Technical Articulation
- AI Leverage
- Ownership
- Market Readiness
- Evidence

Do not invent scores. If evidence is insufficient, use **baseline needed** / **unassessed**. Once quarters are comparable, use simple directional movement (`↑`, `→`, `↓`, `◌`) plus a short evidence note instead of false numeric precision.

Every snapshot ends with exactly four decision sections: **KEEP**, **BUILD**, **REDUCE**, and **NEXT QUARTER BETS**. BUILD should contain only 1–2 deliberate capabilities; NEXT QUARTER BETS has a maximum of two.
