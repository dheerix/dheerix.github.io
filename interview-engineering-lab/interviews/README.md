## Before each company session

Replace hypotheses with evidence from the current job description, recruiter
guidance, and known interview stages. Then choose questions from the shared labs
that exercise the highest-priority gaps.

## Mock cadence

- One 10-minute topic screen after every learning session
- One 35–45 minute system-design mock each week
- One 35-minute coding mock each week
- Two behavioral stories with adversarial follow-ups each week

Record answers, terminology gaps, and corrections in `mock-log.md`; summarize the
result in `../PROGRESS.md`.
