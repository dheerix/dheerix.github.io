# Architecture Decision Records

Record only decisions that reveal meaningful interview reasoning. Use this format:

```text
# ADR-NNNN — Decision title
Status: Proposed | Accepted | Superseded
Date: YYYY-MM-DD

## Context
What constraints and forces make this a decision?

## Decision
What are we choosing?

## Alternatives considered
What realistic options did we reject, and why?

## Consequences
What becomes easier, harder, riskier, or more expensive?

## Interview explanation
Give the 60-second version without implementation detail.
```

Decisions should be revisited when an experiment invalidates an assumption.
